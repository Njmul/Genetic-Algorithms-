
Constraints for Genetic Program for KP
• Number of individuals: 128
• Generation limit: 3,000
• Input data file name : kp_dataset(100).txt, kp_dataset(300).txt
Evolution progress and the best 2 results(sum of item’s weights and sum of item’s values, and individual description) should be printed.
Test condition
• 2 kinds of different weight limits
• The program is to be run 5 times for 2 kinds
• The average value of all results will be the final score
